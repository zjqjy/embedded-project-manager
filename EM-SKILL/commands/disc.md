# 命令: /em disc (讨论流程)

## 功能
进入需求对齐讨论流程（5阶段）

## 触发
```
/em disc [讨论ID]
```

## 讨论阶段概要

> 阶段 1-5 纯对话不落盘；下表产出文件在**阶段 5 用户确认后统一写入** `<STATE_DIR>/features/S<N>-<slug>/`。

| 阶段 | 产出文件 | 说明 |
|------|---------|------|
| 1. 需求拆分 | `split.md` | 分析子系统/模块，用户确认 |
| 2. 需求确认 | `requirements.md` | 追问式确认各子功能详细参数 |
| 3. 硬件对齐 | `hardware.md` | 确认引脚和配置，检查冲突 |
| 4. 头脑风暴 | `plan.md` 方案章 | 讨论技术难点和解决方案 |
| 5. 子流程拆分 | `plan.md` 拆分章 + 索引行 | 拆分为 S[X] 子步骤，同步 features/README.md（v4）或 project-spec.md（v3）|

## 强制完成约束

**在讨论完成（阶段5）之前，禁止执行以下操作**：
- ❌ 编写任何代码、创建或修改文件
- ❌ 执行 `/em result` 或 `/em verify`
- ❌ 完成任务（完成开发步骤）

**如果用户要求提前执行**：
AI 应回复："讨论尚未完成（X/5阶段），请先完成讨论再执行后续操作。输入 `继续` 进入下一阶段。"

## 讨论形式（S18 追问式）

- **AI引导追问** → 用户回答：一次一问、选择题优先（推荐项首位）、每问附「为什么问」，细则见 `workflows/new-clarify.md`
- **阶段 1-5 纯对话不落盘**，用户确认后统一保存（唯一落盘点在阶段 5 之后）
- **确认即保存**：阶段 5 确认后 AI 直接保存全部文件
